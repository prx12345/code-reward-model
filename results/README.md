# results/

Committed outputs. Anything here was produced by a script in `scripts/` and can
be regenerated by re-running it.

- `dataset_stats.json` — dataset sizes, prompt/solution length statistics, and
  the reference-solution harness validation. **Measured.**
- `_pipeline_smoke_test/` — **not results.** Output of the synthetic dev
  fixture, kept only to show the pipeline runs. Read the README in there.

`generalization.json`, `error_analysis__*.json`, `label_report__*.json`,
and the `roc_*.png` / `calibration_*.png` / `confusion_*.png` plots.
